# Contributing

This document outlines the expected workflow and contribution
guidelines. Contributions that do not follow these guidelines
may not be reviewed or merged.

## Development workflow

1. Create feature branch **from the latest version** of the default branch:
   *eg. feature/add-temperature-sensor*

2. Make changes

3. Run tests *(if relevant and tests exist)*

4. Open Pull Request

## Commit format

This project follows a commit message convention to maintain a clean and readable history.

See `.github/COMMIT_CONVENTIONS.md` for formatting rules and examples.

## Pull Requests

- Keep PRs small
- Link related issue
- Provide a short description of the changes
- Ensure the project builds successfully *(if applicable)*
- Verify that tests pass *(if available)*
